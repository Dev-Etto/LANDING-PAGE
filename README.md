# LANDING-PAGE

Este projeto foi desenvolvido como estudo durante o aprendizado das tecnologias HTML, CSS e design responsivo. Ele consiste em uma landing page para o "Balle Bot", um bot que ajuda a moderar comunidades no Discord.

Você pode ver mais do projeto atravez do link [Land-Page]( https://landing-page-beta-jet.vercel.app/)

## Tecnologias Utilizadas
- HTML5
- CSS3
